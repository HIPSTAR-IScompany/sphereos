# Legacy generations, service closure, and versions

Keep SphereOS 3.x and 4.x, AQC, and Atlantis specifications and implementation records distinct. Preserve historical achievements, personas, and static registers without presenting ended services as operating. Copying data alone does not restore identical personality or authority.

## Coordinates and distribution aliases

- Existing 0.250.1 is the Presentation.Function.SemanticKernel coordinate under sphere-version-coordinate/1.
- 0.25.1 and 0.25.1-alpha.1 remain legacy distribution aliases.
- sphere-context-os-coordinate/2 is a Target Contract using UserContextSolution.SDKSeries.ProtocolKernelGeneration.

Do not copy matching numbers across generations automatically. Keep release channel, Solution, SDK, and Protocol distinct; this is not ordinary semantic versioning.

This initial projection does not move or delete legacy services or original Git history. Retain old URLs and artifact lineage in the Q Atlantis migration ledger.
