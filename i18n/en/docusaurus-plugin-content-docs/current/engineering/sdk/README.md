# Components and SDK

Sharing a documentation site does not merge implementations or distributions into one component.

| Component | Questions to ask |
|---|---|
| ASTRO file | Which persona design, memory references, equipment, and execution contracts are carried? |
| ASTRO Runner | Which models and tools are connected, under which authority? |
| Instance Ghost | How are session and branch experiences and provenance retained? |
| IBD and IFD | Which storage, acquisition, and portable-state responsibilities are covered? |
| FAM and FQuery | How are semantic units referenced and queried? |
| Atlantis | Which World management, boundary, resource, and recovery tasks are covered? |

ASTRO remains independent. Inclusion does not make an Atlantis bundle mandatory or establish a shared runtime. This explanatory map is not a list of implemented APIs.

Before implementing, read the target repository's AGENTS, README, schemas, and tests. Verify capabilities, untested scope, and dependencies. Names and workspace membership do not create import relationships or write authority.
