# Architecture and current state

SphereOS Atlantis is an OS architecture lineage addressing Worlds, meaning, authority, resources, isolation, and recovery. Read design, development workbenches, component implementations, and standalone runtime separately.

## Workbench and runtime

The adopted Manifest distinguishes Architect and Bootstrap tooling and Prompt Engineering Edition from the standalone runner and core runtime. A blanket “no runner” claim erases existing CLI and enforcement harnesses. Their existence does not establish a completed general-purpose OS runtime.

Waiting for funding, electricity, or compute is distinct from design failure or a frozen lineage. Attach the component, revision, and tests when updating implemented, untested, unimplemented, and resource-wait states. Do not judge research meaning solely by runtime availability or replace runtime evidence with narrative.
