# componentとSDK

統合文書サイトへ同居することは、実装や配布物を一つへ吸収することではありません。

| component | 読むときの問い |
|---|---|
| ASTRO file | 人格設計・記憶参照・装備・実行契約のどこを運ぶか |
| ASTRO Runner | どのmodel／toolへ、どの権限で接続するか |
| Instance Ghost | セッションや分岐ごとの経験・来歴をどう保持するか |
| IBD／IFD | 保存・取得・可搬状態のどこを担当するか |
| FAM／FQuery | 意味単位の参照と問い合わせをどう扱うか |
| Atlantis | World管理・境界・資源・復旧をどこまで担うか |

ASTROは独立componentです。掲載だけでAtlantis必須bundleや同一runtimeにしません。表は説明用の責務図であり、実装済みAPI一覧ではありません。

実装へ進む際は、対象repositoryのAGENTS、README、Schema、testを読み、能力・未試験・依存を確認します。名前やworkspaceの同居からimportやwrite権限は生成されません。
