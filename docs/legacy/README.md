# 旧世代、サービス終了、版数

SphereOS 3.x／4.x、AQC、Atlantisの仕様と実装実績を同じ現在状態へ潰しません。旧世代の実績や人格・静的レジスターは保存し、終了したサービスを現在稼働として表示しません。旧データのコピーだけで同一人格・同一権限の復元とも判定しません。

## 座標と配布alias

- 既存0.250.1はsphere-version-coordinate/1のPresentation.Function.SemanticKernel座標。
- 0.25.1／0.25.1-alpha.1は保持するlegacy distribution alias。
- sphere-context-os-coordinate/2はUserContextSolution.SDKSeries.ProtocolKernelGenerationを扱うTarget Contract。

同じ数字を世代間で自動copyせず、release channel・Solution・SDK・Protocolを区別します。通常のmajor.minor.patch SemVerへの読み替えではありません。

初回projectionは、旧サービスや原典のGit履歴を移動・削除する作業ではありません。旧URLと成果物の来歴はQ Atlantisの移植台帳へ残します。
